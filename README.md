# Andhra Pradesh District Explorer

Interactive Leaflet map with 28 Andhra Pradesh district records and links to the corresponding Notion notes pages.

## Features
- Interactive district polygons loaded from an open GeoJSON boundary dataset.
- Click a district to highlight it and open its matching Notion notes page.
- District chip index remains available as a fallback.
- Quick notes can be saved in the current browser; permanent notes belong in Notion.
- Responsive layout for desktop and mobile.

## Publish with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Set **Branch** to `main` and folder to `/(root)`, then click **Save**.
5. Wait for GitHub Pages to finish its first deployment.

Your site URL will be:
https://sasidhar462.github.io/andhra-pradesh-district-map/

The map uses Leaflet and OpenStreetMap tiles (© OpenStreetMap contributors). District outlines come from an open GeoJSON repository and are for general reference, not legal or cadastral use.
